🌐 Accès Réseau Local

Pour jouer depuis d'autres appareils sur le même réseau :

Remplacez localhost par l'adresse IP de cette machine

Exemple : http://192.168.1.100:3000

L'adresse IP exacte s'affiche dans la console du serveur lors du démarrage

Utilisez Node.js pour la communication WebSocket entre les appareils
